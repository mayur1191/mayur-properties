# 🏠 Mayur Properties — Luxury Real Estate in Dubai

A modern, fully responsive real estate website built with **React + Vite**, showcasing premium properties across Dubai's most prestigious communities.

![React](https://img.shields.io/badge/React-18.3-61DAFB?logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-6.0-646CFF?logo=vite&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Features

- **16 Property Listings** across 10 Dubai locations
- **Filter System** — filter by type (1BHK, 2BHK, 3BHK, 4BHK, Villa) and location
- **Payment Booking Modal** with card input and confirmation
- **5 Pages** — Home, About, Properties, Amenities, Contact
- **Gym & Swimming Pool** sections with image galleries
- **Dark Luxury Theme** with gold accents
- **Fully Responsive** — mobile, tablet, and desktop
- **Lato Font** with Font Awesome icons

## 🗂️ Pages

| Page | Description |
|------|-------------|
| **Home** | Hero with Dubai skyline, search bar, featured properties, stats, locations, testimonials |
| **About** | Company story, mission & vision, team members, achievements |
| **Properties** | Full catalogue with type/location filters and booking |
| **Amenities** | Gym, swimming pool, spa, sports courts, cinema room & more |
| **Contact** | Contact form, office locations, branch addresses |

## 🛠️ Tech Stack

- **Frontend:** React 18, React Router DOM
- **Build Tool:** Vite
- **Styling:** Vanilla CSS with custom properties
- **Fonts:** Google Fonts (Lato)
- **Icons:** Font Awesome 6
- **Images:** Unsplash

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/mayur1191/mayur-properties.git

# Navigate to project
cd mayur-properties

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
